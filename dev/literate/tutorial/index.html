Tutorial

This tutorial walks through the main features of LatticeProteins.jl: encoding amino acid sequences, computing contact energies and folding probabilities, and sampling sequences that fold into a target structure.

Setup

Since the package does not export any symbols, we import the names we need explicitly. (Alternatively, everything is reachable through the LatticeProteins. prefix.)

using LatticeProteins: pnat, log_pnat, energy, onehot, aaseq, potts, AMINO_ACIDS,
    metropolis!, random_msa, CONTACT_MAP_A, CONTACT_MAP_B,
    CONTACT_MAPS, N_STRUCTURES, MJ, Hugo_MSA, Hugo_MSA_pnat

A lattice protein is a chain of 27 amino acids folded onto a 3×3×3 cubic lattice. The package ships with 10,000 pre-computed compact structures (contact maps):

N_STRUCTURES
10000

Four of these structures are highlighted in Jacquin et al. (2016) and exposed as constants CONTACT_MAP_A, CONTACT_MAP_B, CONTACT_MAP_C and CONTACT_MAP_D. Each is simply an index into the structure database:

CONTACT_MAP_A
625

Encoding sequences

Sequences are written as strings over the AMINO_ACIDS alphabet (20 amino acids plus a gap character):

AMINO_ACIDS
"CMFILVWYAGTSNQDEHRKP-"

Most numerical routines work with integer-coded (Potts) sequences, where each amino acid is replaced by its index in the alphabet. Use potts to convert:

seq = potts("EKAMPAMDPDMAHEHKKKIRAWMFEGE")

We can convert back to a string with aaseq:

aaseq(seq)
"EKAMPAMDPDMAHEHKKKIRAWMFEGE"

A sequence can also be one-hot encoded into a 21 × 27 BitMatrix with onehot, which is convenient for machine-learning workflows:

X = onehot("EKAMPAMDPDMAHEHKKKIRAWMFEGE")
size(X)
(21, 27)

Energy and folding probability

The contact energy of a sequence in a given structure is the sum of Miyazawa-Jernigan interaction energies over all contacting residue pairs:

energy(CONTACT_MAP_A, seq)
-93.82

The same sequence has a different energy in a different structure:

energy(CONTACT_MAP_B, seq)
-67.96

The probability that a sequence folds into a particular "native" structure is given by a Boltzmann distribution over all 10,000 competing structures. This is pnat (and its logarithm log_pnat):

pnat(CONTACT_MAP_A, seq)
0.994633330791981
log_pnat(CONTACT_MAP_A, seq)
-0.005381121507544653

Sampling sequences that fold

We can search for sequences that fold into a target structure using Metropolis Monte Carlo. random_msa starts from random sequences and evolves each one at inverse temperature β; a large β strongly favours sequences with high folding probability for the target structure.

msa = random_msa(CONTACT_MAP_A; nseqs = 20, β = 100, nsteps = 200)
size(msa)
(27, 20)

Each column of the returned matrix is an integer-coded sequence. The sampled sequences fold into structure A with high probability:

using Statistics: mean
mean(pnat(CONTACT_MAP_A, col) for col in eachcol(msa))
0.774418481164577

metropolis! exposes the same sampler for a single sequence, mutating it in place:

s = potts("EKAMPAMDPDMAHEHKKKIRAWMFEGE")
metropolis!(s, CONTACT_MAP_A; β = 100, nsteps = 200)
pnat(CONTACT_MAP_A, s)
0.9437391987944209

Reference datasets

The package also bundles the reference multiple sequence alignments (MSAs) and their folding probabilities from Jacquin et al. (2016), accessible with Hugo_MSA and Hugo_MSA_pnat:

sequences = Hugo_MSA(:A)
length(sequences)
46265
pnat_values = Hugo_MSA_pnat(:A)
first(pnat_values, 5)
