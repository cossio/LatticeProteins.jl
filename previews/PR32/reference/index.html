Reference

This page documents all symbols provided by LatticeProteins.jl. None of them are exported, so they must be accessed with the LatticeProteins. prefix or imported explicitly (e.g. using LatticeProteins: pnat).

LatticeProteins.LatticeProteins — Module
LatticeProteins

Simulate the lattice proteins model on a 3×3×3 cubic lattice in Julia.

A lattice protein is a simplified model where a protein sequence of 27 amino acids folds on a 3×3×3 cubic lattice. The energy of a sequence in a given structure is determined by pairwise contacts using the Miyazawa-Jernigan interaction matrix. The probability that a sequence folds into a structure is a Boltzmann distribution over the competing compact structures: by default the 10,000 reference structures of Jacquin et al. (2016), or all 103,346 compact structures of the lattice (see enumerate_structures).

References

  • Jacquin, Hugo, et al. "Benchmarking inverse statistical approaches for protein structure and design with exactly solvable models." PLoS computational biology 12.5 (2016): e1004889.

Structures and contact maps

LatticeProteins.CONTACT_MAPS — Constant
CONTACT_MAPS

Pre-loaded contact maps of the 10,000 reference compact structures. An Array{Int, 3} of size (28, 10000, 2). Use CONTACT_MAPS[:, s, :] to get the contact pairs for structure s. See load_contact_maps.

These are the structures used by Jacquin et al. (2016), and the default set of competing structures in pnat and metropolis!. They are a subset of the 103,346 compact structures of the lattice, which can be generated with enumerate_structures.

LatticeProteins.load_contact_maps — Function
load_contact_maps()

Load the pre-computed contact maps of the 10,000 reference compact structures on the 3×3×3 cubic lattice used by Jacquin et al. (2016). Returns an Array{Int, 3} of size (28, 10000, 2), where CONTACT_MAPS[:, s, :] gives the 28 pairs of contacting residue indices for structure s.

LatticeProteins.enumerate_structures — Function
enumerate_structures()

Enumerate all maximally compact structures of a 27-mer on the 3×3×3 cubic lattice, that is, all self-avoiding walks visiting the 27 lattice sites, modulo the 48 rotations and reflections of the cube. There are 103,346 of them. The chain direction is kept: reversing the chain maps contact (i, j) to (28 - j, 28 - i), which in general gives a different contact map, so a structure and its chain reversal count as distinct structures (62 of them are their own reversal).

Returns an Array{Int, 3} of size (28, 103346, 2) with the same layout as CONTACT_MAPS: structures[:, s, :] gives the 28 contact pairs of structure s, as rows (i, j) with i < j, sorted lexicographically. The enumeration order is deterministic. Takes a few seconds.

The 10,000 reference structures of CONTACT_MAPS are a subset of these; use structure_index to locate one of them. Pass the result as the structures keyword argument of energy, pnat, log_pnat, metropolis! or random_msa to compute folding probabilities over all compact structures instead of the 10,000 reference ones:

ALL = enumerate_structures()
a = structure_index(ALL, CONTACT_MAP_A)
pnat(a, seq; structures = ALL)

References

  • Shakhnovich, E. I., and A. M. Gutin. "Enumeration of all compact conformations of copolymers with random sequence of links." The Journal of Chemical Physics 93.8 (1990): 5967-5971.

LatticeProteins.structure_index — Function
structure_index(structures, cm::AbstractMatrix{Int})
structure_index(structures, cm::Int)

Index within structures of the structure with contact map cm, or nothing if it is not there. structures is an array of structures such as CONTACT_MAPS or the output of enumerate_structures. cm is a 28 × 2 matrix of contact pairs, such as CONTACT_MAPS[:, CONTACT_MAP_A, :]; the order of the contacts and the order within each pair are ignored. If cm is an integer, it refers to the reference structure CONTACT_MAPS[:, cm, :].

Example

ALL = enumerate_structures()
a = structure_index(ALL, CONTACT_MAP_A)  # index of reference structure A in ALL
pnat(a, seq; structures = ALL)

Energy and folding probability

LatticeProteins.energy — Function
energy(cm::Int, seq::AbstractVector{Int}; structures = CONTACT_MAPS)

Compute the contact energy of amino acid sequence seq in structure cm.

The energy is the sum of Miyazawa-Jernigan interaction energies over all contacting residue pairs in the given structure. seq must be a vector of length 27 with integer amino acid indices in 1:20. cm is the index of the structure in structures, which defaults to the 10,000 reference structures CONTACT_MAPS and can be set to the output of enumerate_structures.

source
LatticeProteins.energies — Function
energies(seq::AbstractVector{Int}; structures = CONTACT_MAPS)

Contact energies of seq in every structure of structures, as a Vector{Float64} of length size(structures, 2). Equivalent to [energy(s, seq; structures) for s in 1:size(structures, 2)], but faster.

See also energy.

LatticeProteins.pnat — Function
pnat(cm::Int, seq::AbstractVector{Int}; structures = CONTACT_MAPS)

Probability that sequence seq folds into structure cm. Equivalent to exp(log_pnat(cm, seq; structures)).

See also log_pnat.

source
LatticeProteins.log_pnat — Function
log_pnat(cm::Int, seq::AbstractVector{Int}; structures = CONTACT_MAPS)

Compute the log-probability that sequence seq folds into structure cm (the "native" structure), as opposed to any of the other structures in structures.

The probability is computed using a Boltzmann distribution at temperature 1 over the structures in structures:

\[\log P_\text{nat}(\text{cm} \mid \text{seq}) = -\log \sum_s \exp\bigl(E(\text{cm}, \text{seq}) - E(s, \text{seq})\bigr)\]

By default structures is the set of 10,000 reference structures CONTACT_MAPS used by Jacquin et al. (2016), which is a subset of the 103,346 compact structures of the lattice. To sum over all of them, pass structures = enumerate_structures() (see enumerate_structures).

See also pnat, energy.

AMINO_ACIDS

Sampling

LatticeProteins.metropolis! — Function
metropolis!(seq::AbstractVector{Int}, cm::Int; β=1, nsteps=1, structures=CONTACT_MAPS)

Perform Metropolis Monte Carlo sampling on the amino acid sequence seq, targeting structure cm. The sequence is mutated in place.

At each step, a random position is selected and mutated to a random amino acid (1–20). The move is accepted or rejected using the Metropolis criterion with inverse temperature β, where the energy is -log_pnat(cm, seq; structures).

The energies of seq in all structures are kept and updated incrementally after each mutation, so a step costs much less than a call to log_pnat.

Arguments

  • seq: integer-coded amino acid sequence of length 27 (values in 1:20).
  • cm: target structure index (in structures).
  • β: inverse temperature (higher values favor sequences that fold into cm).
  • nsteps: number of Monte Carlo steps to perform.
  • structures: set of competing structures, by default the 10,000 reference structures CONTACT_MAPS. Pass the output of enumerate_structures to compete against all compact structures.

Returns the mutated seq.

source
LatticeProteins.random_msa — Function
random_msa(cm::Int; nseqs=1, β=1, nsteps=1000, structures=CONTACT_MAPS)

Generate a random multiple sequence alignment (MSA) of nseqs sequences that fold into structure cm, using Metropolis Monte Carlo sampling.

Each sequence is initialized randomly and then evolved for nsteps Metropolis steps at inverse temperature β. Returns a Matrix{Int} of size (27, nseqs), where each column is an integer-coded amino acid sequence. structures is the set of competing structures (see metropolis!).

See also metropolis!.
