Tutorial

This tutorial walks through the main features of LatticeProteins.jl: encoding amino acid sequences, computing contact energies and folding probabilities, and sampling sequences that fold into a target structure.

Setup

The package exports its public API:

using LatticeProteins

A lattice protein is a chain of 27 amino acids folded onto a 3×3×3 cubic lattice. There are 103,346 maximally compact structures (counted up to rotations and reflections of the cube), which the package enumerates when it is installed:

length(enumerate_structures())
103346

Structures are referred to by their index in this enumeration. Four of them are highlighted in Jacquin et al. (2016), and their indices are the constants STRUCTURE_A, STRUCTURE_B, STRUCTURE_C and STRUCTURE_D:

STRUCTURE_A
22451

The 28 contacts of structure A, as pairs of residue positions:

Encoding sequences

Sequences are written as strings of amino acids, in one-letter code. Most numerical routines work with integer-coded (Potts) sequences, where each amino acid is replaced by its index in the alphabet "CMFILVWYAGTSNQDEHRKP-" (20 amino acids plus a gap character). Use potts to convert:

We can convert back to a string with aaseq:

aaseq(seq)
"EKAMPAMDPDMAHEHKKKIRAWMFEGE"

A sequence can also be one-hot encoded into a 21 × 27 BitMatrix with onehot, which is convenient for machine-learning workflows:

X = onehot("EKAMPAMDPDMAHEHKKKIRAWMFEGE")
size(X)
(21, 27)

Energy and folding probability

The contact energy of a sequence in a given structure is the sum of Miyazawa-Jernigan interaction energies over all contacting residue pairs:

energy(STRUCTURE_A, seq)
-93.82

The same sequence has a different energy in a different structure:

energy(STRUCTURE_B, seq)
-67.96

The probability that a sequence folds into a particular "native" structure is given by a Boltzmann distribution over all competing compact structures. This is pnat (and its logarithm logpnat):

pnat(STRUCTURE_A, seq)
0.47413471332741575
logpnat(STRUCTURE_A, seq)
-0.7462637923336448

Sampling sequences that fold

We can search for sequences that fold into a target structure using Monte Carlo. sample_msa samples an alignment with the method it is given. The simplest, Metropolis, starts from random sequences and evolves each one at inverse temperature β; a large β strongly favours sequences with high folding probability for the target structure.

result = sample_msa(STRUCTURE_A, Metropolis(β = 100, nsteps = 1000); nseqs = 20)
msa = result.samples
size(msa)
(27, 20)

Each column of the alignment is an integer-coded sequence. The sampled sequences fold into structure A with high probability:

using Statistics: mean
mean(pnat(STRUCTURE_A, col) for col in eachcol(msa))
0.9072913449133637

For strong selection, where a single chain mixes slowly, the method ParallelTempering runs replicas over a ladder of inverse temperatures, and reports how well they exchange:

ladder = ParallelTempering(betas = [0.0, 1.0, 10.0, 100.0], burnin = 200, thin = 5)
result = sample_msa(STRUCTURE_A, ladder; nseqs = 20)
result.diagnostics.swap_accepts ./ result.diagnostics.swap_attempts
3-element Vector{Float64}:
 0.02
 0.0
 0.0

sample_msa takes a random number generator as the keyword argument rng, for reproducible runs.

Internals: the model of Jacquin et al. (2016)

Not part of the public API

This section uses internal names, which can change in any release. The public API is the model above, where all compact structures compete.

Jacquin et al. (2016) restricted the competing structures to a representative subset of 10,000 selected by the Shakhnovich group (Heo, Maslov & Shakhnovich 2011). The package uses that model to check itself against published results, and downloads the subset the first time shakhnovich_structures is called:

using LatticeProteins: shakhnovich_structures, structure_index, Hugo_MSA, Hugo_MSA_pnat
S10 = shakhnovich_structures()
StructureSet with 10000 structures of 28 contacts

The functions above accept the set of competing structures through the internal structures keyword argument. Structure indices refer to the set in use, and structure_index translates between sets. Structure A is number 625 of the subset:

a = structure_index(S10, STRUCTURE_A)
625

The subset has fewer competitors, so folding probabilities computed against it are higher than against all compact structures:

pnat(a, seq; structures = S10)
0.9946333307919798
pnat(STRUCTURE_A, seq)
0.47413471332741575

Sampling works the same way:

msa_ref = sample_msa(a, Metropolis(β = 100, nsteps = 200); nseqs = 5, structures = S10).samples
mean(pnat(a, col; structures = S10) for col in eachcol(msa_ref))
0.8178056556440554

The package also provides the reference multiple sequence alignments (MSAs) of Jacquin et al. (2016) and their folding probabilities, with Hugo_MSA and Hugo_MSA_pnat. The folding probabilities were computed against the subset:

sequences = Hugo_MSA(:A)
length(sequences)
46265
pnat_values = Hugo_MSA_pnat(:A)
